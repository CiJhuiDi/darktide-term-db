# 暗潮术语库 (Darktide Term DB)

战锤 40K:暗潮 机制术语数据库——收集游戏内名词,描述其作用,并记录术语之间的关联关系。

> 状态:**立项 v0.3**(数据 63 条,去留待用户定稿;demo 可用)

## 功能目标

- **术语词典**:撕裂/脆弱/暴击/踉跄/韧性/护甲类型……收集游戏内机制名词 + 官方中英文名 + 作用描述
- **关系网络**:术语之间的关联(爆头 ↔ 弱点 ↔ 弱点伤害;撕裂 ↔ 护甲 ↔ 穿透),支持点击跳转/图谱
- 最终形态:游戏内 mod(聊天命令查询 / 界面浏览);当前先以 HTML demo 迭代数据

> 🚫 **禁止编造**:本项目的描述/数值/解锁条件必须来自官方文本、游戏文件数据、ENLocalizationFIX 或用户确认;拿不准先问用户(用户 2026-08-18 指定)。

## 数据来源

- **官方中文完整文本**：`暗潮\03-技能树\数据\darktide_zh_loc.json`（LocalizationExport 导出，139724 键）——提取术语官方译名与出处
- **官方术语表**：`loc_glossary_*`（22 条：护甲类型/被动/能力/楔石/光环/闪击等）——官方基准层
- **游戏内数据整理 + 实测验证**：参考游戏文件与玩家实测校准机制（如 rending=撕裂/破甲、brittleness=脆弱/每层2.5%增伤）
- **ENLocalizationFIX 系列**：游戏 mods 目录（Blessings/Curios/Talents/Traits），中文描述重写实测级细节；已归档 `references\enloc_fix_ref\`（含术语提取_参考 + 机制描述_精华）
- **人工校对**：用户逐条定稿（去留/描述/关联）

## 数据格式

```js
{ t:"撕裂", en:"Rending", cat:"damage", keep:true,
  src:"天赋(执行指令:获得撕裂)", d:"降低目标护甲减伤(破甲),叠层后对高护甲敌人伤害显著提升。",
  r:["护甲","脆弱"] }
```

- `cat`:damage 伤害机制 / defense 防御机制 / action 攻击动作 / gear 装备属性
- `keep`:true=建议收录 / false=待定
- `r`:关联术语(中文名,双向;UI 点击跳转)

## 重要勘误(防再错)

- **撕裂 = Rending** = 降低护甲减伤(破甲);**脆弱 = Brittleness** = 每层 2.5% 受伤加深
  (v0.2 曾将 brittleness 误标为撕裂,官方天赋原文佐证后已修正)
- **链锯撕裂(Sawing)** 是链锯武器锯割机制,与撕裂/脆弱均无关

## 使用 demo

直接双击打开 `demo/index.html`（**自包含单文件**，数据内嵌，任何环境可用，无需服务器）。

> 数据维护：只改 `data/terms.js`（数据源），然后运行 `python tools/build_demo.py` 重新生成 demo。
