# 校对协作说明(多人协作)

## 流程总览

```
我导出校对表 → 你分发(在线表格/文件) → 多人填写 → 你回收放 reviews/ → 我分析 + 你裁决 → 合并进数据
```

## 步骤

### 1. 导出校对表

```bash
python tools/export_review.py            # 全量(174 条)
python tools/export_review.py --limit 30 # 试跑小批量
```

输出:`reviews/校对清单_<日期>.csv`(UTF-8 BOM,Excel 直接打开)。

### 2. 分发

- **方式一(推荐)**:上传到腾讯文档/飞书/石墨在线表格,分享链接,多人同时填,自动聚合
- **方式二**:直接发 CSV 文件给每人,各自填写

### 3. 填写规范

| 列 | 填写 |
|---|---|
- 状态列填：✅已校对 / ❓有异议 / ⚠️争议（emoji 或文字均可，如"已校对/有异议/争议"，打错字也能识别）
| 意见 | 具体改什么、为什么;争议时双方意见都写(`张:... 李:...`) |
| 验证方式 | 🅰️游戏文件(附字段)/ 🅱️实测(附怎么测)/ 🅲️社区 |
| 校对者 | 名字(或文件命名为 `校对_名字.csv`) |

### 4. 回收

把填好的文件(可多个)放进 `reviews/` 文件夹,命名 `校对_<名字>.csv`。
在线表格则导出 CSV 放进同一目录。然后告诉我"校对照收了"。
**提交节奏(对外约定)**: 玩家随时填、随时发(邮件/文件均可), 不用赶进度——统一在**每周日**汇总合并、反馈。

### 5. 分析 + 裁决

```bash
python tools/merge_review.py
```

输出 `reviews/校对分析报告_<日期>.md`:
- 进度统计(已校对/有异议/争议/待校对)
- 验证方式分布(游戏文件/实测/社区)
- 校对者统计
- ⚠️ 争议清单(双方意见保留,我查证后给事实依据)
- ❓ 有异议清单

**裁决规则**:
1. 我能查证的(游戏文件/官方文本)→ 直接定,标注依据
2. 定不了的 → 整理成"待拍板清单"给你
3. 裁决结果写入词条备注(留痕,防复吵)

### 6. 合并

裁决确认后,我把结论合并进 `data/terms.js`,demo 自动更新(✅/❓/⚠️ 徽标)。

## 文件约定

- `reviews/` 本地协作目录(已 gitignore,不进仓库)
- 校对文件命名:`校对_<名字>.csv`(按人统计)
- 导出/分析脚本在 `tools/`

## 邮件收件(校对者不固定时)

校对者为社区热心玩家、不固定某个人时:让校对者填写后**以附件(校对_<名字>.csv)回复/发送到你的 QQ 邮箱**,
本机脚本自动拉取附件存入 `reviews/`(按附件名识别,不依赖发件人白名单)。

### 配置(一次性)
1. QQ 邮箱设置 → 账户 → 开启 **IMAP/SMTP 服务**,生成**授权码**(不是登录密码)
2. 编辑 `reviews/.mail_config.json`(已 gitignore,不进仓库):
```json
{"user": "你的邮箱@qq.com", "auth_code": "IMAP/SMTP授权码"}
```

### 收件
```bash
python tools/mail_review.py fetch            # 近7天
python tools/mail_review.py fetch --days 14  # 近14天
python tools/mail_review.py fetch --all      # 全部邮件
python tools/mail_review.py fetch --merge    # 收完自动跑 merge_review.py
```
- 附件名匹配 `校对_*.csv`,已存在且内容相同自动跳过;同名不同内容加时间戳保存
- 只处理附件名为校对表的邮件,不读取其他邮件内容

### 发件(可选)
```bash
python tools/mail_review.py send 对方邮箱 --attach reviews/校对清单_<日期>.csv
```
校对者不固定时也可由你自己分发清单,脚本只负责收。

## 批量收发(社区发帖邀请场景)

帖子/表单收集玩家邮箱后,批量发清单、批量收回复:

### 1. 收集邮箱
- 建议用**表单**(腾讯问卷/石墨表单)收集,不要在帖子回帖留邮箱(公开邮箱易被爬虫抓垃圾邮件)
- 导出邮箱列表存为 `reviews/player_emails.txt`(每行一个,支持 # 注释)

### 2. 批量发送
```bash
python tools/mail_review.py send_batch reviews/player_emails.txt --attach reviews/校对清单_<日期>.csv --delay 5
```
- 邮件正文已含填写说明(状态/验证方式/重命名规则)
- **QQ 邮箱频率限制**:建议单批 ≤30 封、间隔 ≥5s;失败地址会列出可重试

### 3. 批量收取
```bash
python tools/mail_review.py fetch --merge   # 收全部校对_*.csv 附件并自动合并
```
- 玩家直接**回复原邮件**、附件命名 `校对_<昵称>.csv` 即可,自动识别

## 邮箱报名(玩家发关键词邮件,公开招募场景)

公开招募时把**用户邮箱本身当报名入口**:玩家发一封主题/正文含关键词(如"参与校对")的邮件即报名,无需第三方表单。

### 1. 收集报名
```bash
python tools/mail_review.py signups                       # 默认关键词"参与校对", 近7天
python tools/mail_review.py signups --keyword 校对 --days 14
```
- 搜索主题/正文含关键词的邮件 → 提取发件人邮箱(去重) → 写入 `reviews/player_emails.txt`
- 玩家只需发一封信(内容可只有"参与校对"几个字), 隐私比公开回帖留邮箱更好

### 2. 批量发送清单
```bash
python tools/mail_review.py send_batch reviews/player_emails.txt --attach reviews/校对清单_<日期>.csv --delay 5
```
- QQ 邮箱限流: 单批 ≤30 封、间隔 ≥5s;失败地址列出可重试

### 3. 批量收取校对表
```bash
python tools/mail_review.py fetch --merge
```
- 玩家回复原邮件、附件命名 `校对_<昵称>.csv` → 自动识别存入 reviews/ → 自动合并

### 隐私与风险
- 公开邮箱 = 可能收到垃圾邮件/广告(用户已接受);报名邮件只有本机脚本处理,不外泄
- 建议帖子说明: 报名邮件仅用于发送校对清单,不会用于其他用途
